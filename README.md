# jiansketch.com

The home of **JIANSKETCH** — clean neo-Y2K art archive with the singing wall.
Design language: **neo-Y2K street-pop** — the rickys.place skeleton (light,
clean, notched tabs) × the Japanese street-pop game-UI / 90s print-poster
style from `Pictures/style_guide` (Persona 5 / ZZZ promo graphics, AKIRA
posters): ink outlines, hard offset shadows, halftone grain, shout type,
sticker buttons, starburst badges, window-chrome boxes, barcode footers.

Type: Anton (shout display), Fredoka (rounded display), M PLUS Rounded 1c
(UI/body), PixelOperatorMono (labels) — all subset to latin woff2 in
`assets/fonts/` (196KB total; TTF sources in `tools/fonts_src/`).
Static site: plain HTML/CSS/JS, no build step, no dependencies. Fast everywhere.

## How the wall works

- `data/art.js` is the manifest (`window.JIAN_ART`), generated by
  `tools/optimize_art.py` from the raw archive.
- `assets/js/wall.js` builds the tiles grouped into **year sections**
  (2026 → 2020 + PROJECTS), hover pops, particle bursts, the year filter
  chips + sidebar index, the **GRID S/M/L density control** (persisted),
  lightbox (arrow keys + esc work), and the PARTY button.
- `assets/js/sfx.js` synthesizes every sound with WebAudio — there are no
  audio files. Hovering pops a bubble-pop voice that climbs an A-minor
  pentatonic scale, stereo-panned by tile position. Browsers require one
  real click before audio can start — the toast at the bottom covers that.

## Adding new art

1. Drop the original into `raw/art-gallery/<year>/` (any `png/jpg/webp/gif`;
   `2026` is already wired up — the wall section appears automatically).
2. Run `python tools/optimize_art.py` (needs `pip install Pillow`).
3. Commit the new files in `art/` + `data/art.js`. Done.

One tile per piece, SFW only — the July 2026 cleanup pulled WIPs, duplicate
variants, promos and anything NSFW out of the wall set. Keep that rule when
adding. `tools/contact_sheets.py 2026` builds labeled review grids into
%TEMP%\jian_review if you want to eyeball a batch before publishing.

## Deploy (GitHub Pages)

1. Create a repo, e.g. `jiansketch/jiansketch.github.io` (or any repo and use
   the project-pages URL).
2. Push this folder: `git init && git add . && git commit -m "new site" && git push`.
3. Repo **Settings → Pages → Source: Deploy from a branch**, pick `main` / root.
4. Custom domain: `CNAME` already contains `jiansketch.com`. At your DNS
   provider point the apex at GitHub (`185.199.108.153` … `.111.153`, four
   A records) and/or `www` as a CNAME to `<user>.github.io`, then tick
   **Enforce HTTPS** once the cert issues.

The old neocities site can stay up as the time capsule — link to it whenever.
